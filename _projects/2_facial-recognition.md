## Overview

Designed and deployed a facial recognition pipeline for enterprise staff monitoring, optimized for high accuracy and real-time performance at scale.

## Technical Details

### Technologies Used
- **Deep Learning**: Face detection and embedding models
- **Vector Database**: Milvus for efficient similarity search
- **Hardware**: GPU 5070Ti optimized
- **Processing**: Real-time video stream analysis

### Key Features
- High-accuracy face embedding extraction
- Vector similarity search for fast identification
- Scalable architecture for large employee databases
- Real-time video processing pipeline

## Results & Impact

- **>90% accuracy** on face recognition
- **25 FPS** real-time processing on GPU 5070Ti
- Efficient similarity search via Milvus vector database
- Scalable for large number of employees
